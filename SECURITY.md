# Security Policy

## Scope

This repository hosts signed macOS release archives and Ed25519-signed update manifests (`interface-update.json`) for **Interface**. Application source code is published in [KilianTheMagnificent/interface](https://github.com/KilianTheMagnificent/interface) (see its [SECURITY.md](https://github.com/KilianTheMagnificent/interface/blob/main/SECURITY.md) for app-level security reporting).

## Reporting a Vulnerability

If you discover a security issue with a published release artifact, signature, manifest, checksum, or updater feed in this repository, please **do not** open a public issue.

Instead, report it privately via [GitHub Security Advisories](https://github.com/KilianTheMagnificent/interface-releases/security/advisories/new) with:

- The affected release tag or asset filename.
- Steps to reproduce or verify the issue.
- Any relevant hashes, logs, or impact details.

Reports are reviewed by the maintainer as promptly as possible, and confirmed issues will be addressed with an updated release and advisory where appropriate.
