# Interface — Release Builds & Update Feed

Signed macOS release builds and update manifests for **Interface**, maintained by [Andre Romero-Carey](https://github.com/KilianTheMagnificent).

- **Purpose of this repository:** Hosts signed macOS installer archives and Ed25519-signed `interface-update.json` manifests used by Interface's built-in updater via [GitHub Releases](https://github.com/KilianTheMagnificent/interface-releases/releases).
- **Source code & installer:** Open-source at [KilianTheMagnificent/interface](https://github.com/KilianTheMagnificent/interface).
